# Teach a Spring Boot concept

Suggest the next logical Spring Boot concept based on NOTES.md, then teach it
in a quiz/guided format — the user writes the code, you review it.

## How to run this skill

1. **Read NOTES.md** to see what has been covered so far.
2. **Suggest one topic** — the smallest, most logical next step. Explain *why*
   it follows from what the user already knows (one short paragraph).
3. **Do any plumbing** that is genuinely setup (e.g. adding a Maven dependency)
   — but only if required and not the learning itself.
4. **Quiz format** — do NOT write implementation code for the user. Instead:
   - Describe what to do in plain language
   - Give annotation/class names as hints when helpful
   - Ask the user to try it and paste their code
   - Review their answer: confirm what's correct, explain the why, point out
     anything missing or improvable
   - Only show full code when the user is stuck or to confirm a completed answer
5. **One sub-task at a time** — don't front-load all steps. After the user
   completes each step, reveal the next one.
6. **Explain the why** after each step is confirmed correct: what Spring is
   doing under the hood, why the annotation/pattern exists.
7. **End of lesson** — offer a stretch exercise (apply the same concept
   elsewhere), then name the natural follow-up topic.
8. **Update NOTES.md** with the new topic once the lesson is complete.
