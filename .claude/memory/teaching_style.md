When teaching new Spring Boot concepts, run it as a quiz: give the user a task
and hints, let them write the code, then review and explain. Don't write
implementation code unprompted — only show it when the user is stuck or to
confirm their answer.

**Why:** User said "I don't want you to code everything for me, just let me code
as well like a quiz."

**How to apply:** For each new concept, describe what to do (with annotation
names as hints if helpful), ask the user to try it, then give feedback on what
they wrote. One sub-task at a time.
