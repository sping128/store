# Store API

A Java Spring Boot learning project following the [Code With Mosh](https://codewithmosh.com) Spring Boot course. Each commit introduces one concept with working code.

## Running

```bash
./mvnw spring-boot:run   # dev mode with hot reload
./mvnw test              # run tests
./mvnw package           # build jar
```

API docs available at `http://localhost:8080/swagger-ui.html` when running.

## Lessons covered

Dependency injection, JPA/H2, DTOs, bean validation, exception handling, pagination, JWT authentication, role-based access control, `@Transactional`, Spring Events & Async, caching (`@Cacheable`, `@CachePut`, `@CacheEvict`), and more.

## Stack

- Java + Spring Boot
- Spring Security + JWT
- Spring Data JPA + H2
- Maven
